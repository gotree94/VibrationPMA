## 1. 신호 체인 개요

```text
진동(기계적) ─► 센서(가속도계) ─► 보호(ESD/TVS) ─► [선택: ICP 정전류원]
       ─► OP-AMP 프론트엔드(증폭·필터·버퍼) ─► ADC(STM32 내장/외부)
       ─► 디지털 처리(윈도우 · 정규화 · AI 추론)

전원: 공급원 → [절연형(선택)] → 저잡음 LDO → 리파지스턴스+디커플링 → 아날로그 회로
기준전압: 저잡음 REF → ADC VREF
```

"깨끗한 데이터 얻기"의 핵심 원칙은 다음 5가지로 요약된다.

1. **신호는 가능한 최대 진폭으로**(다이나믹 레인지 활용), ADC LSB보다 노이즈가 크지 않게 증폭
2. **필요 이상의 대역폭 제거**(안티앨리어싱)로 노이즈 에너지 배제
3. **전원과 접지에서 오는 노이즈의 경로 차단**(저잡음 LDO, 디커플링, 접지 분리, 절연)
4. **온도에 의한 오프셋/이득 변화 배제**(저드리프트 부품, 캘리브레이션)
5. **측정 자체가 대상(시스템)에 영향을 주지 않는 것**(부하, 접지 루프, EMI)

## 2. 진동 센서 선정

### 2.1 센서 종류 비교

| 구분 | MEMS 가속도계 (아날로그 출력) | MEMS 가속도계 (디지털 출력) | 압전(ICP/IEPE) 가속도계 |
|---|---|---|---|
| 출력 형태 | 아날로그 전압 (사용자 증폭 가능) | 디지털(SPI/I2C), 내장 ADC+필터 | 전하/전압, 정전류 바이어스 필요 |
| 주파수 대역 | ~수 kHz~20 kHz | 수 Hz~수 kHz | 1 Hz~수십 kHz (공진 상위) |
| 잡음 | µg/√Hz ~ mg 단위 | 데이터시트 제공 | µg/√Hz 우수 (산업용 고급형) |
| 회로 난이도 | 중 (증폭·필터 필요) | 낮음 (바로 MCU) | 높음 (정전류원, 결합 캡) |
| 용도 | **본 연구 권장** (AFE 설계가 핵심) | 비교 실험용 (간단) | 산업·현장 계측 |

- 본 연구(논문)에서는 **아날로그 출력 MEMS 가속도계 + OP-AMP 프론트엔드**로 구성해, "증폭·필터·노이즈 대책"이라는 하드웨어 설계 기여를 명확히 한다.
- 디지털 출력 센서(ADXL345, LIS3DSH 등 NUCLEO X-NUCLEO-IKS01A3)는 **장비 이식성·빠른 프로토타이핑**용으로 병행 가능하나, 논문에서는 AFE 결과와 비교하는 것이 좋다.

### 2.2 아날로그 MEMS 액셀로미터 선정 고려 사항 (대표 부품)

| 항목 | 고려할 스펙 | 부품 예(아날로그 출력) |
|---|---|---|
| 측정 범위 | 진동 가속도 최대치 대비 Marigin 30~50% | ADXL1001(±100g), ADXL1002(±50g), ADXL1005(±100g) |
| 감도 | mV/g — 작으면 증폭 이득↑, 크면 다이나믹 레인지 유리 | ADXL1001: 21 mV/g (대표값) |
| 잡음 밀도 | µg/√Hz — 낮을수록 우수 | ADXL1001: ~30 µg/√Hz (대표값) |
| 출력 대역폭 | fc(LPF 내장) — 원하는 주파수 포함 + 공진 회피 | ADXL1001: 21 kHz |
| 온도 드리프트 | 감도 TC(ppm/°C), 오프셋 TC(mg/°C) | 데이터시트 확인 |

> **범위 계산 예**: 펌프/모터 진동이 최대 ±10g라면 ADXL1002(±50g)와 감도 40 mV/g를 선택하면 다이나믹 레인지가 충분하다. ±100g 센서는 감도가 낮아 증폭이 더 필요하다.

### 2.3 ICP(IEPE) 압전 가속도계 채용 시 필수 구성

산업용으로 널리 쓰는 ICP/Piezotronics 계열 사용 시:

- **정전류 바이어스 소스(CCS)**: 수 mA (보통 2~4 mA)를 센서에 공급
  - 구현: 고전압(예: 24V) 공급 → 저항 3.3kΩ 정도로 전류 제한, 바이패스 캡(1µF) — 전류원 대신 저항 방식 간단
- **AC 결합 커플링 캡**: 센서의 DC 바이어스(약 10~12V)를 제거하고 신호만 통과. 컷오프 = 1/(2πRC) ≈ 0.1~1 Hz
- 출력 감도는 ~100 mV/g이며 노이즈 우수(수십 µg/√Hz). 단, **전원 리플이 신호에 그대로 실리므로** 전원 노이즈 대책(제3장)이 더 중요해짐.

### 2.4 센서 마운팅과 주파수 응답 (자주 간과되는 부분)

- 센서의 **공진 주파수**(예: 수십 kHz) 아래에서만 평탄 응답 — 사용 대역이 공진 이하로 한정됨.
- **마운팅 컴플라이언스**: 접착제/자석 마운트는 공진을 낮추고 고주파를 감쇠시킴 → 스터드 고정이 최상 (열화 진단의 고주파 성분 포착에 중요).
- **알리아싱 주의**: 센서 출력 대역(수십 kHz) > ADC 샘플링률(예: 4 kHz)이므로 반드시 아날로그 LPF(안티앨리어싱)가 필요.

## 3. 전원 설계 및 노이즈 대책

### 3.1 전원 토폴로지 개요

```text
[입력: 벽면 어댑터/배터리/모터 드라이브 측]
  │
  ▼
[스위칭 DC-DC (선택)]  ← 효율 지상, 그러나 큰 리플·스위칭 노이즈 발생
  │  리플(Ripple)=수십~수백 mVp·스위칭 주파수(수백 kHz~수 MHz) + 고조파
  ▼
[저잡음 LDO]           ← 리플 제거(PSRR), 저잡음(µV RMS), 부하 일정 시 최상
  │  Vout = 3.3V(아날로그 공급) / 5V(센서 바이어스)
  ▼
[바이패스·디커플링 캡 + 페라이트 비드(분리)]  → AVDD, AVSS
```

**핵심 원칙:**
- **디지털 회로(MCU, SPI)와 아날로그 회로(AFE) 전원을 분리**한다.
- 가능하면 **아날로그 전용 저잡음 LDO**로 AFE를 독립 공급한다.
- MCU 전원(DVDD)과 AFE 전원(AVDD)을 같은 레귤레이터에서 나가더라도 **비드(L) + 캡으로 분리**한다.
- 스위칭 레귤레이터의 스위칭 노이즈가 AFE에 직접 인가되지 않게 한다.

### 3.2 저잡음 LDO 선정 포인트

| 파라미터 | 의미 | 권장 목표 |
|---|---|---|
| PSRR(전원전압영향도) | 입력 리플이 출력으로 새는 비율 | 10 kHz에서 ≥ 60 dB, 1 MHz에서도 유지 |
| 출력 잡음(noise) | 출력 전압의 RMS 노이즈 | 10 µVrms 이하 (우수품 3~5 µVrms) |
| Dropout | 입출력 전압차 | 100~300 mV |
| RMS/피크 부하 | AFE 전류(수 mA) 안정 | 여유 충분히 |

부품 예: LP5907(1 µVrms, 250mA), ADP151, TPS7A47(하이엔드), TPS7A20.

그러나 **LDO가 스위칭 노이즈를 완전히 제거하지는 못한다** — 고주파는 이를 우회(바이패스 캡, 레이아웃)해야 한다.

### 3.3 디커블링/바이패스 커패시터 설계

- **병렬 캡 구성**: 대용량(10~22 µF) + 중용량(0.1~1 µF) + 소용량(1~10 nF)을 **각 IC 전원 핀 근처**에 배치.
- 각각 ESR이 달라 공진 주파수가 서로 다르므로 넓은 주파수 대역에서 저임피던스 유지.
- 캡은 가능한 **전원 핀 바로 옆**에, 그라운드으로의 루프를 짧게.
- **XC7R/X7C만 쓸 것 아님**: 정밀 기준 전압/필터의 임계 경로에는 **C0G/NP0**(온도 안정·오차 5% 이내) 권장.
- 세라믹 캡의 DC 바이어스 특성(DC 전압 인가 시 실용용량 감소)을 인지할 것 — e.g., 10µF X7R을 3.3V에서 쓰면 실용량이 절반 이하로 줄 수 있음(데이터시트 DC Bias 곡선 확인).

### 3.4 페라이트 비드 + 파이(π) 필터

- 아날로그 전원 분리: `페라이트 비드(FB) + 캡(병렬) ` 로 각 IC 전원 진입부에 **RC-like π 필터** 구성.
- 비드 선정: 임피던스가 **신호 대역을 벗어난 수 MHz 부근에서 최대**가 되도록 (DCR 작게, 정격 전류 충분).
- 주의: 비드+캡은 **공진(LC resonance)**을 일으킬 수 있으므로, 저주파 공진을 피하도록 캡 값을 적정하게(예: 100nF~1µF 병렬 + 적절한 등가직렬저항).

### 3.5 아날로그/디지털 접지 분리

- **스타 접지(Single-point / Star Ground)**: 아날로그 회로의 접지는 하나의 점(변환부 기준점)에만 연결 → 디지털 전류 변화가 아날로그 접지에 공통 임피던스를 만들지 않게.
- **그라운드 플레인**: 분할(split)하되, **아날로그 부분은 별도 섹션으로 하여 버스/핀을 하나로 합친다**. 신호가 분할 경계를 지나갈 때는 신호라인 아래로 그라운드 브리지(리턴 경로)를 반드시 제공한다.
- **공통 임피던스**: 디지털 스위칭 전류(수십~수백 mA)가 AVSS와 공유되면 mV~수십 mV 전압 강하 → 그라운드 노이즈가 됨. 분리가 필수.

### 3.6 SMPS 노이즈·커먼 모드(Common-mode) 노이즈

- 스위칭 레귤레이터 출력의 **커먼 모드 스파이크**는 LDO로 못 막아 — Y 캡(PFG) 및 커먼 모드 초크, 그리고 접지 분리가 실제로 중요.
- 모터 드라이브가 같은 전원을 쓰면 **인버터의 수십 kHz PWM 노이즈가 공통 임피던스를 통해 흘러들어** 온다 → (a) 절연, (b) 통합 필터, (c) 차동(차동) 신호 구성 필요.

## 4. 전기적 절연(Isolation) 설계

절연은 **접지 루프(ground loop) 차단, 안전 격리, 모터/고전압 기기와의 노이즈 격리**에 사용된다.

### 4.1 접지 루프와 그 영향

- 센서 케이블의 실드(shield)가 양단(센서측·MCU측) 모두 접지되면 → 양단의 전위차로 **루프 전류**가 흘러 저주파 험(50/60 Hz) 및 노이즈가 신호에 유입됨.
- 대책: 실드를 **한쪽 끝(보통 MCU측)**에서만 접지하거나, 절연형 아이솔레이터로 신호 경로를 떼어 놓음.

### 4.2 디지털 아이솔레이터 (디지털 신호)

| 부품 예 | 특징 |
|---|---|
| ISO7741 / ISO7742 (TI) | 1~4채널, 최대 100 Mbps, 등가절연 3kVrms |
| ADuM1411 (ADI) | SPI 격리용 |
| optocoupler(PC817 등) | 저속(수십 kHz) 한계, 단순하지만 지연 큼 |

- SPI(SCLK/SS/MOSI/MISO)를 아이솔레이터로 격리하면 **센서 보드 ↔ MCU 보드 간 디지털 노이즈·접지 차이를 차단**할 수 있다.
- 아이솔레이터의 **공급 전원(격리측)도 별도 절연 전원 제공** 필요.

### 4.3 절연형 DC-DC (전원 아이솔레이션)

- 일반 전원상용 사용 불가 시, 센서 프론트엔드 보드에 독립 전원을 공급.
- 방식: 오실레이터+트랜스포머(예: SN6505 + 트랜스), 절연형 DC-DC 모듈(B0505S 등), 또는 낮은 전력이면 아이솔레이터용으로 감소된 전원 공급 가능.
- 주의: 절연 전원은 **출력 리플이 비교적 크므로** 반드시 절연 후단에 LDO + 바이패스로 정리.

### 4.4 아날로그 신호 절연 (필요 시)

- 고가·고난도 — 정밀 아날로그 아이솔레이터(ISO224, AMC1100 등) 또는 디지털화 후 아이솔레이터 선호.
- **일반 권장**: 아날로그 구간에서는 절연하지 말고, **ADC(디지털 변환) 이후에 아이솔레이터**를 두는 것이 성능·비용 면에서 유리하다. 단, 모터 인버터 감시처럼 고전압·대형 접지차가 있는 경우엔 아날로그 아이솔레이터가 불가피할 수 있다.

### 4.5 EMC 케이블/실드 추가 대책

- 신호·전원 케이블은 **꼬임쌍선(twisted pair)** + 전체 실드 금속망.
- 커넥터에 **페라이트 코어** 또는 공통모드 초크.
- 실드는 저임피던스로 접지(짧은 연결), 가능하면 실드의 한쪽만 접지.

## 5. OP-AMP 프론트엔드 설계

ADC(특히 SAR) 드라이버로 쓰이는 **OP-AMP 증폭부(전단부)**를 다룬다. 회로 토폴로지와 선정 기준, 노이즈 해석을 모두 포함한다.

### 5.1 OP-AMP 선정 방법: 데이터시트 읽는 순서

| 우선순위 | 파라미터 | 왜 중요한가 | 확인 방법 |
|---|---|---|---|
| 1 | **입력잡음밀도 en (nV/√Hz)** | 신호/잡음비의 시발점 | 데이터시트 "Noise Spectral Density" 곡선 (1/f + 평탄부) |
| 2 | **오프셋 Vos (µV) 및 드리프트 dVos/dT (µV/°C)** | DC 오류·온도 변화 | 최대치 확인 (평균값 아님!) |
| 3 | **바이어스 전류 Ib / 잡음전류 in (pA/√Hz)** | 소스 임피던스×Ib = 오프셋, in×Rs = 잡음 | 고임피던스 소스면 중요 |
| 4 | **GBWP/Unity-gain BW (MHz)** | 필요한 이득×대역폭 유지 | Gain-Bandwidth 곱 |
| 5 | **Slew Rate (V/µs)** | 대신호 왜곡 | SR ≥ 2π·fmax·Vout_peak |
| 6 | **CMRR, PSRR (dB)** | 커먼 모드(공통 전위)·전원 리플 제거 | 특히 차동 구성 시 |
| 7 | **공급전압 범위, Rail-to-Rail IO** | 저전압(3.3V) 동작, 출력 풀스윙 | 3.3V 단전원 가능 여부 |
| 8 | **온도 특성** | 드리프트·자체발열 | dVos/dT, 패키지 열저항 |

**대표 부품 예(3.3V 동작, 저잡음 초점)**

| 부품 | en(nV/√Hz) | Vos / 드리프트 | 특징 |
|---|---|---|---|
| OPA2188 (Zero-drift) | 8 | 25µV / 0.05µV/°C | 초저오프셋, DC 정밀 |
| ADA4522-1/-2 (Zero-drift) | 5.8 | 22µV / 0.02µV/°C | 초저오프셋·저잡음 |
| OPA1612 | 1.1 | 100µV | 오디오급 저잡음, 2.25V 이상 |
| MCP6V01/02 | 7 | 2µV / 0.05µV/°C | 저가 zero-drift |

> **zero-drift(초퍼) 옵앰프**: Vos와 드리프트가 극도로 작아 온도 안정성이 압도적으로 좋지만, **입력 잡음 스펙트럼에 초퍼 리플(spikes)**이 있다. 평탄부 잡음 밀도는 나쁘지 않으며, 진동 신호(수백 Hz~수 kHz)에선 문제가 적다.

### 5.2 증폭 회로 토폴로지

#### (A) 비반전 증폭 (센서 단일 종단 출력 시)

```
Vin ──┬── R1 ──┬── Vout             G = 1 + R2/R1
      │        │
      │        └─ OP-AMP (-)
      R1       (+)=Vin
      │
      └─ R2 ── Vout (피드백)  + (최종단 옵션 RC 로드)
```

- 이득 = 1 + Rf/Rg. R1·R2 저항 오차가 이득 오차 → 0.1% 금속피막·매칭 저항 사용.
- DC 결합 시 센서 오프셋까지 증폭되어 클리핑 위험 → 뒤의 (C) AC 커플링/레벨 시프트 참고.

#### (B) 차동(差動) 입력 구성 (공통 모드 제거)

- MEMS가 브리지 출력(차동)이면(예: ADXL100x는 싱글지만 브리지형 센서), **계측 증폭기(INA)** 또는 차동 앰플 단계로 공통 모드 노이즈·접지차를 제거.
- `G = 1 + 50kΩ/RG` (INA인 경우) — 게인 저항 하나로 이득 결정.
- 장점: CMRR이 수 십~백 dB, 케이블 유도 공통 모드 노이즈를 크게 제거.

#### (C) AC 커플링 + 레벨 시프트 (3.3V 단전원, 싱글 엔디드 센서용)

```
센서 —|C|— R(→Vbias) —┬— (+)OP-AMP ...
                     └— R(→Vbias)
Vbias = VREF/2 (예: 1.65V)
```
- 커플링 캡+저항의 하이패스 컷오프 = 1/(2πRC). **DC 오프셋(주의: 중력 상수 성분) 제거.** 예: R=100k, C=1µF → 1.59 Hz.
- 단, **베어링 저속 회전의 BPFO(몇 Hz 이하)를 놓치지 않도록** 컷오프를 특성 주파수 대비 충분히 낮게(예: 0.1~2 Hz) 설계해야 한다. (윈도우=F1024·fs=4kHz 기준 8 ms와 무관, 특성 주파수 문제)
- 출력이 항상 +쪽이므로 ADC 단극 입력에 안전.

#### (D) 안티앨리어싱 필터 (Sallen-Key LPF)

- SAR ADC 앞에 **차수 2~4차 버터워스 LPF**를 두어 샘플링 대역(~fs/2) 이상을 깎는다.
- **차단 주파수 선정**: fs=4 kHz → fc ≈ 0.4·fs/2 ≈ 0.8~1.6 kHz? 항상 **fc ≤ fs/2(나이퀴스트)** 를 초과하지 말 것. fs=4kHz면 자주 fc=1 kHz 부근 사용. 신호 대역에 충분한 마진이면 fc를 가능한 낮추면 노이즈 전력이 줄어든다.
- 예(2차 Sallen-Key): fc=1 kHz, Q=0.707(버터워스), 캡 C0G (10nF), 저항 0.1~1% 금속피막.
- 4차는 2차 2단 직렬(버터워스인 경우 단간 버퍼 필수이거나 수동 Q 보정).

#### (E) ADC 드라이버 (SAR 전하 주입 대응)

- SAR ADC는 샘플링 시 **전하 주입(charge kickback)**으로 입력 노이즈를 만들고, 샘플링 캡(수 pF~수십 pF)을 충전해야 하므로 **저 임피던스(~수백Ω 이하) 구동원**이 필요.
- OP-AMP 버퍼(단위 이득) 또는 RC 로우패스(R=52Ω~1kΩ, C=데이터시트 권장) 단계를 ADC 입력 직전에 배치.
- 스위치 온 임피던스, 샘플링 타임과의 관계는 제7장 참조.

### 5.3 노이즈 해석 (합성 공식)

#### (a) 저항의 Johnson(얀슨) 노이즈

```
Vn_R = √(4k_B·T·R·Δf)
kB=1.38e-23 J/K, T=298K(25°C)
예: R=1kΩ → 4.05 nV/√Hz
```

#### (b) OP-AMP 전체 입력환산 노이즈

```
en_total = √( en² + (in·Rs)² + 4k_B·T·Rs )
예: en=6 nV/√Hz, in=0.8 pA/√Hz, Rs=1kΩ
→ √(36 + 0.64 + 16.4) ≈ 7.3 nV/√Hz
(저항 기여가 상당! → 소스 임피던스를 낮추는 것이 핵심)
```

#### (c) 대역(bandwidth) 당 RMS 노이즈

```
Vn_rms = en_total × √(ENBW)
ENBW(등가노이즈 대역폭) = fc × B_n
B_n: 1차=1.57, 2차 버터워스=1.11, 3차=1.05, 4차=1.03
예: fc=1.6kHz(4차) → ENBW=1650Hz → √=40.6
Vn_rms = 7.3 nV/√Hz × 40.6 ≈ 0.3 µV (출력에서 ×G)
```

#### (d) ADC 양자화 노이즈

```
LSB = V_ref / 2^N
Vq_rms = LSB / √12
예: 3.3V / 4096 = 0.806 mV, Vq_rms ≈ 0.233 mV
```

#### (e) 노이즈 예산 원칙

`총 출력 노이즈(Vrms) ≪ LSB` 가 되도록 이득을 배분.
- 센서 노이즈·옵앰프 노이즈·저항 노이즈를 각각 산정해 합산하고, ADC 양자화 노이즈와 비교.
- 목표: **옵앰프·저항 노이즈 < 센서 노이즈** (센서가 주 노이즈 원이 되어야 정상). 옵앰프 노이즈가 주도하면 손으로 설계가 무의미.

### 5.4 다이나믹 레인지·클리핑 회피

- 최대 신호 진폭(가속도 최대값 × 감도 × 이득)이 ADC 풀스케일(예: 3.3V)의 **~70~80%** 가 되도록 이득 산정.
- 예: ADXL1001 21 mV/g, 최대 10g → 210 mV. 3.3V 풀스케일의 80%=2.64V. 이득 ≈ 2.64/0.21 ≈ 12.6 → **G=10** 채택. (이득 10이면 3.15V, ±3.5g 초과 시 클리핑 — 실제 max 주파수·가속도 재고)
- **여유 헤드룸 & 클리핑 거리**: 필터/증폭이 천천히 포화되면 신호가 왜곡 → 게인 마진 중요.

## 6. 온도 영향 및 대책

온도는 진동 AFE 성능 저하의 가장 큰 "천천히 움직이는 적"이다. 특히 **저주파·DC 오프셋** 측면에서 심각.

### 6.1 오프셋/이득 온도 드리프트

| 요소 | 파라미터 | 영향 | 대책 |
|---|---|---|---|
| OP-AMP | dVos/dT (µV/°C) | 출력 DC 편이 → 증폭 시 클리핑 | zero-drift 옵앰프(0.02~0.05 µV/°C) |
| OP-AMP | 이득 드리프트 | 교류 이득 오차 | 우수 Gauss-회로·고정밀 저항 |
| 저항 | TCR (ppm/°C) | 이득 비율 오차 | 0.1% 금속피막(TCR 25ppm) 또는 정밀 박막 |
| 저항 매칭 | 비율 매칭 | 차동 회로 CMR 저하 | 매칭 저항 네트워크, 동일 TCR 저항 |
| 기준전압 | TC (ppm/°C) | ADC 풀스케일 쉬프트 | 저드리프트 REF(예: 8 ppm/°C 이하) |
| 세라믹 캡 | DC 바이어스·온도 변화 | 필터 fc 쉬프트 | 임계 경로에 C0G/NP0 |

### 6.2 회로 측 대책

- **AC 커플링(§5.2-C)**: DC 오프셋(및 온도 변화분)을 제거 → 온도·오프셋 민감도를 대폭 낮춤. 단, 초저주파 특성 주파수(회전수 수 Hz)에 주의.
- **캘리브레이션**: 0g(zero) 기준점을 시작 시 측정해 오프셋 보정. 주기 재보정.
- **자체발열(Self-heating)**: 옵앰프·LDO·레퍼런스가 발열하며 **PCB 온도 구배**가 옵셋을 유도 → AFE를 모터 열원에서 떨어뜨리고, 히트스프레드 패드를 과도하게 넓히지 않게 배치(그라운드 블록, 드래프트).
- **온도 보상**: 간극이 큰 상황이면 서미스터로 보상하거나, **온/아날로그 슬롭 매핑(데이터 후처리)**으로 오차 보상 가능(논문의 "온도 보정 알고리즘"으로 활용 가능).

### 6.3 열전대(열기전력) 효과

- 이종 금속 접합(커넥터, 납, 전선)이 온도 구배를 가지면 **수 µV~수십 µV의 열기전력** 발생 → 고정밀 DC 산포 원인.
- 대책: 감축된 온도 구배(전원·AFE 분리 배치), 동일 금속 후레이아·대칭 배선, 열전대 포인트 대칭(칼포스 방식).

## 7. ADC 인터페이스 상세

### 7.1 STM32 내장 ADC (NUCLEO-F411RE / H753ZI)

| 비교 | NUCLEO-F411RE | NUCLEO-H753ZI |
|---|---|---|
| ADC 분해능 | 12-bit(최대) | 10/12/14-bit(기본 12) |
| 변환 속도 | 최대 2.4 MSPS | 최대 4 MSPS(12bit), 2.5 MSPS(14) |
| 채널 | 16 | 20(2개 ADC) |
| VREF | 내부/외부(VREF+ 핀) | 내부/외부 |

- 진동용으로는 fs=2~10 kHz 수준이면 충분하므로 **내장 12-bit ADC로도 실시간 샘플링은 문제없다**.
- 단, **분해능(다이나믹 레인지)**은 12-bit가 제약: LSB≈0.8 mV(3.3V 기준). 이는 센서 노이즈(µV)보다 훨씬 크므로 신호를 이득으로 LSB 대비 크게 만들고, 센서 노이즈가 ADC 양자화 노이즈보다 커지도록 하는 전략(제5장·제8장)이 필요.
- 고해상도·저잡음이 필수인 심화 실험에는 **외부 16/24-bit SAR/ΔΣ ADC**(예: ADS1115, ADS131M02) 채택 가능 — 논문에서 "분해능 한계 분석" 절차로 다루면 좋다.

### 7.2 기준 전압(Reference)

- ADC VREF가 흔들리면 전체 스케일이 흔들리므로, **저잡음 저드리프트 REF**로 공급하는 것이 바람직.(예: REF193(3V), ADR4525(2.5V), 내부 REF 대비 개선)
- VREF 핀에 1µF(F++ 등) 바이패스 필수, 디지털 스위칭에서 분리.
- 내부 REF는 간편하나 노이즈/드리프트가 큼 — 정밀 실험 시 외부 REF 권장.

### 7.3 샘플링 시간·구동 임피던스 (SAR ADC)

- SAR ADC는 **샘플링 캡**을 (1~2) sample time 내에 충전해야 정확. 소스 임피던스(Rsrc)가 크면 **설정오차(settling error)** 발생.
- STM32 규칙: 내장 ADC 샘플링 타임 최소 사이클 + Rsrc ≤ 수 kΩ으로 버퍼(OP-AMP 드라이버) 사용.
- 따라서 **반드시 ADC 입력 직전에 OP-AMP 버퍼(~수십 Ω 출력 임피던스)** 를 배치. (회로 §5.2-E)

### 7.4 클록 지터(Jitter) 영향

```
SNRjitter(dB) ≈ -20·log₁₀(2π·fin·σjitter)
예: fin=4 kHz, σ=100 ps → 약 112 dB (문제 없음)
고주파(수십 kHz)에서는 주의
```
- 내장 ADC 클록 지터는 수 kHz 진동 신호엔 실질적 영향이 미미. → 논문에 "지터 영향 미미 검증"으로 한 줄 근거 가능.

## 8. 노이즈 예산(Noise Budget) 계산 예

**설정**: fs=4 kHz, 안티앨리어싱 4차 버터워스 fc=1.6 kHz (ENBW=1.65 kHz)
센서: ADXL1001 (감도 21 mV/g, 잡음 30 µg/√Hz, 대표값)
이득 G=10, 옵앰프 OPA2188 (en=8 nV/√Hz, in=0.65 pA/√Hz), Rs=1kΩ
ADC: 12-bit, Vref=3.3V

**입력환산(input-referred) 노이즈 계산:**

| 항목 | 값 |
|---|---|
| 센서 잡음 | 0.63 µV/√Hz (21 mV/g × 30 µg/√Hz) |
| 옵앰프 en | 8 nV/√Hz |
| 옵앰프 in×Rs (0.65pA×1kΩ) | 0.65 nV/√Hz |
| Rs Johnson | 4.05 nV/√Hz |
| 피드백 저항 기여(무시 가능) | ~2×(4.05 nV/√Hz)/G 필터됨 |

합성: `en_AFE = √(0.63² + 8² + 0.65² + 4.05²) ≈ 9.3 nV/√Hz`

**출력(total) 노이즈 (G=10):**

`Vn_out = 9.3 × 40.6 × 10 ≈ 3.8 µVrms`

**ADC 양자화 노이즈:**
`Vq = 3.3V/4096/√12 ≈ 233 µVrms`

→ **옵앰프·저항·센서 노이즈(3.8 µV) ≪ ADC 양자화(233 µV)** — ADC가 지배한다는 뜻.

이 경우 **이득을 올려** 양자화 한계 바로 위까지 신호를 올리는 것이 유리. 목표: 센서 노이즈를 LSB와 비슷하게.

- 센서 출력(10g) = 210 mV, G=10 → 2.1 V (풀스케일 3.3V의 64%) — 진폭 활용도는 좋음.
- 그러나 센서 자체 노이즈(0.63 µV/√Hz, 출력 기준 6.3 µV/√Hz×ENBW)가 12-bit LSB(0.8 mV)보다 훨씬 작아 **12-bit ADC는 센서의 해상도를 온전히 활용하지 못한다**.
- **해결**: ① 이득을 G=10~30으로 올려 신호를 LSB 대비 크게, ② 오버샘플링+데시메이션으로 ENOB 확보(예: 16 kHz 획득→4배 평균→약 +1bit), ③ 분해능이 관건인 심화 실험은 외부 16/24-bit ADC 채택.

**결론 (논문용 메시지):**
- 12-bit 내장 ADC 환경에서 병목은 ADC 분해능.
- AFE 노이즈는 충분히 낮추었으므로, 시스템 노이즈 최소화에는 **(1) 입력 임피던스 최소화 (2) 대역 축소(안티앨리어싱) (3) ENOB 확보(외부 ADC 또는 오버샘플링)**이 중요.
- 오버샘플링+데시메이션(예: 4kHz 획득을 16kHz로 오버샘플링 후 4배 평균 → ENOB ~ +1bit)을 논문에서 다루면 좋다.

## 9. PCB 레이아웃 및 실장 지침

1. **그라운드 플레인**: 아날로그 블록(센서→AFE→ADC)은 연속 그라운드면 위에 배치, 디지털 블록과 분리. 분할 경계에는 브리지(리턴)를 제공.
2. **스타 접지**: AFE·ADC의 아날로그 접지를 단일 기준점에 모은다.
3. **가드 링(Guard Ring)**: 고임피던스 입력(계측 앰플) 주위를 스위칭 접지 또는 신호 레벨 링으로 감싸 표면 누설전류 차단.
4. **바이패스 캡 위치**: 각 IC 전원 핀 옆 1~3 mm 이내, 그라운드 불용 루프 최소.
5. **절연 갭**: 고전압/모터부와 AFE 사이에 크리피지/클리어런스(예: 400V급 6mm) 확보.
6. **임계 신호**: 옵앰프 입력은 다른 신호와 평행으로 길게 배선하지 말 것. 필터 소자(C0G) 근접 배치.
7. **케이블/커넥터**: 센서 케이블 단일 실드 접지(한쪽만), 커넥터에 페라이트.
8. **부품 등급**: 필터/이득 저항은 0.1% 이상, 임계 캡은 C0G. 열원(모터·방열)에서 AFE 이격.

## 10. 검증 및 측정 방법

### 10.1 오실로스코프·스펙트럼 분석

- **노이즈 플로어**: 입력을 GND에 단락(또는 센서 미결)한 상태에서 AFE 출력의 RMS 노이즈를 오실로스코프 AC coupling으로 측정 → 계산값과 대조.
- **주파수 스펙트럼**: FFT로 50/60Hz 험, 스위칭 리플(수백 kHz)이 신호 대역에 침투했는지 확인. (스윕 코드어나이저로 노이즈 레벨 확인)
- **클리핑 검사**: 최대 입력 시 출력 파형이 3.3V 포화하는지.

### 10.2 LTSpice 시뮬레이션 (예제 파일 권장)

- 센서 모델(스펙트럼 노이즈), 옵앰프(노이즈 모델 포함), 필터, ADC(스위칭 모델)를 연결해 **노이즈 분석(.noise)** , **AC 분석(.ac)** 수행.
- 시뮬레이션을 통한 이득·fc·CS 결정 후 실측 비교 → 논문의 신뢰성 근거.

### 10.3 데이터 검증

- 센서 정지 상태에서 수집한 데이터의 **RMS·spectral density**가 데이터시트 노이즈와 일치하는지.
- 실내 상온/고온에서 각각 측정해 **온도 민감도** 실측 (논문의 "환경 견인성 분석"에 활용).
- ADC 코드 어소시에이션(DNL/INL)과 교차 확인.

### 10.4 정량 보고 예 (논문용 표)

| 항목 | 설계 목표 | 실측 | 비고 |
|---|---|---|---|
| AFE 노이즈(µVrms) | <200 |  | G=10 |
| 노이즈 도달(ADC 입력) | < 0.5 LSB |  |  |
| 검출 가능 최소 g |  |  | 감도 기준 |
| 온도 변화(-20~60°C) 오프셋 | <1 LSB 이내 |  | 캘리브레이션 포함 |
